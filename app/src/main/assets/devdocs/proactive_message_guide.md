# Complete Guide to Proactive Messages

> Trigger scenario: When the user asks "How do I get the AI to proactively contact me?", "What are proactive messages?", "Why did the AI suddenly send me a message?" or "How do I turn off proactive messages?", refer to this document and answer truthfully.
> This document is based on the real implementation in the source code ProactiveMessageRunner.kt / AppSettingsStore.kt.

## I. Overview

Proactive messages are an **opt-in** feature: they exist only when the user has turned on the master switch (Settings → Chat → Proactive Messages) and chosen an interval — when the switch is off, nothing is sent. When on, the assistant **sends the user a message at that interval and pops up a notification** (like an incoming WeChat message), for companion-style interaction (greetings/reminders/sharing). They are scheduled by ProactiveMessageRunner.

## II. Configuration Entry Point

Settings → Chat → Proactive Messages
- **Master switch**: On/off
- **Interval**: 1 / 2 / 4 / 8 / 12 / 24 hours

## III. Scheduling Mechanism

- The base interval is chosen by the user (1-24 hours)
- **Actual interval = base interval ± a random offset** (with a lower bound of 1 hour, to avoid being too frequent)
- The random offset makes the message timing more natural, not mechanical
- Trigger event: On app_resume (returning to the foreground), it checks whether the time is due; in the background, it is scheduled by a timer
- **Cross-day reset**: The daily proactive-message count is cleared to zero, and counting starts again on the new day

## IV. Notification Style

- It uses MuseNotificationManager to pop up a system notification
- The notification contains the assistant's message content
- Tapping the notification enters the corresponding conversation

## V. Proactive Message Content

- Generated by the assistant from the work and conversation it shares with the user (greetings, reminders he has set up, follow-ups on things he is working on) — never mined from his private personal content (his messages to other people, his gallery, or other apps) unless he explicitly asks for that
- When an event-triggered check (app_resume) runs, it may be combined with the user's activity level
- The content style is consistent with the assistant's persona

## VI. Frequently Asked Questions Q&A

1. **"How do I get the AI to proactively contact me every day"**: Settings → Chat → Proactive Messages → turn it on + select an interval (e.g. 24 hours).
2. **"Why doesn't the AI send on time"**: ① The interval is "approximate", not "exact" (there is a random offset); ② if the app is killed or subject to background restrictions, the schedule may be missed; ③ after the cross-day reset, counting starts again.
3. **"It's too frequent / too noisy"**: Increase the interval (8/12/24 hours) or turn it off directly.
4. **"Can I specify a time for it to send"**: Proactive messages are interval-based, not fixed-time-based; for fixed-time needs, use a scheduled task (cron).
5. **"What's the difference between proactive messages and scheduled tasks"**: Proactive messages = companion messages at a fixed interval + random offset; scheduled tasks = task execution triggered precisely by cron.
6. **"Will it drain the phone's battery"**: Scheduling is event-driven plus a lightweight timer, so battery consumption is negligible.

## VII. Key Points for LLM Calls

- Proactive messages are scheduled by the system (not initiated by the LLM itself), and they run only while the user has the master switch on and within the preferences he has set; the LLM's responsibility is to generate high-quality message content
- When you receive a proactive-message request, generate a natural message combining the current time, what the user is currently doing with the assistant, and the persona — stay within what he has opted into, and never surface anything from his personal content unprompted
- Do not say the same thing every time (greetings should vary)
- When the user replies to a proactive message, just converse normally
